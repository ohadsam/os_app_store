# Roadmap
1. Real device screenshots for the native apps; real Android install screenshots (replace the drawn illustrations).
2. Hebrew what's-new lines when the sync adds English ones.
3. Push `docs/APP_RELEASE_STEP.md` into every app's release checklist (the store then updates the moment an app ships).
4. Per-app release history view (from the changelogs); "installed apps" export/import.
5. Optional: a signed `latest.json` per app so the store verifies APK checksums itself.
