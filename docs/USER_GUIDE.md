# User guide - OS APPs and Downs

**Open the store:** `https://ohadsam.github.io/os_app_store/` - install it from the browser menu ("Install app" / "Add to Home screen") to get it as an app that also works offline. Language (עב / EN) and light/dark are in the top bar.

## Finding an app
- **Search** looks in names, descriptions, tags and categories, in Hebrew and English (words in any order).
- **Chips**: All / Web & PWA / Android. **Filter & sort** (button next to the search): category, tags (an app must have all chosen tags), sort (recently updated, newest, name), favourites only.
- The heart saves an app to your favourites; "Recently updated" shows what changed in the last two weeks.

## An app page
Screenshots (tap to enlarge), what the app does, what's new in the latest version, the info table (version, release and update dates, platforms, Android version, package id), install instructions with **"Show the full instructions with pictures"**, and links (source, version history, all releases, checksum, report a problem). "Mark: I installed this version" lets the store tell you when a newer version is out.

## Installing
- **Web / PWA**: tap Open. To install a PWA: Chrome menu (⋮) -> Install app / Add to Home screen.
- **Android app (APK)**: tap Download APK, open the file, allow installing from this source once, tap Install; if Play Protect warns, choose "Install anyway". Full illustrated steps: the "How to install" tab. Updating = install the new APK over the old one (data stays).

## About
Copyright, the note that all images were made with AI tools, how to report a problem, the store version and "Check for a store update".

## Permissions and troubleshooting (1.2)
Each Android app page has **Permissions and steps after install**: what the app asks for, why, and what to tap (pop-up permissions, Settings-screen permissions such as exact alarms / full-screen alarms / battery / background location, and the ones granted automatically). **Install troubleshooting** (also on the guide page) explains every block Android may show, including which small "More details" line to expand so "Install anyway" appears.

## Settings
The Settings tab sets the language (Hebrew is the default, English is available), light/dark, and resets favourites and install marks on this device.
