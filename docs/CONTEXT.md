# OS APPs and Downs - project context (START HERE)

Read this first in a new session. Keep it current: the release checklist requires it and `tests/unit/docs.test.js` fails when a source file is missing from the file map.

## What it is
The owner's private **app store**, a PWA (no Android shell, no server, no account): a catalog of every app the owner built. Web apps / PWAs open from the store; Android apps (APK) download from their GitHub release with a full, illustrated install guide. Store look: search, platform chips, filter sheet (category, tags, sort, favourites), cards, detail pages with screenshots, what's new, info table, install instructions ("show more"), links, report-a-problem, copyright + "all images made with AI tools" notice. Hebrew first (RTL), English equal. Name: "OS APPs and Downs" (OS = the owner's initials; "Ups and Downs" with Ups spelled APPs). URL when deployed: `https://ohadsam.github.io/os_app_store/`.
Owner's rules: `.claude/skills/release-checklist/SKILL.md` §0. Requests ledger: `docs/REQUESTS.md`. Catalog how-to: `docs/CATALOG.md`. Generic method: `.claude/skills/app-development/` (this store follows its PWA half; Android parts do not apply).

## How to run and verify
`npm install` · `npm run serve` (http://localhost:8080) · `npm run check && npm test && npm run e2e` · `npm run journey -- <dir>` (screenshots of every screen he+en) · `npm run sync -- --local /path/to/clones` (catalog vs real apps).

## Architecture in one picture
`ui/*` -> `catalog.js` (pure: normalise/search/filter/sort) / `store.js` (device prefs) / `i18n.js` -> `util.js`. Data = `web/data/apps.json` (network-first in the service worker, so a new version shows at once). No dependencies, CSP `'self'` only, DOM only through `h()`.

## Data model (`web/data/apps.json`, sanitised on read by `normalizeCatalog`)
`{ generated, tags{id:{he,en}}, categories{id:{he,en,icon}}, apps[] }`. App: `id, name, tagline, description, highlights, whatsNew ({he,en}), platforms[web|pwa|android], category, tags[], version, released, updated, status, icon, color, links{web,apk,sha,releases,repo,changelog}, apk{state direct|page|none, pkg, minAndroid, private, note}, shots[{file,caption}], source{repo,file,regex,changelog,heading}` (`source` is for the sync script only). Per-device prefs (localStorage `os.*`): language, theme, favourites, "I installed version X".

## File map (every source file and its job)
- `web/index.html` - shell + strict CSP; `web/manifest.webmanifest`; `web/sw.js` - offline-first worker (catalog + version.json network-first); `web/version.json`; `web/icon.svg`, `web/icons/*` (generated by `scripts/make-icons.mjs`).
- `web/js/app.js` - entry: shell, hash router (`#/`, `#/app/<id>`, `#/guide`, `#/about`), catalog loading + offline fallback, theme/lang.
- `web/js/appVersion.js` - the running version (kept equal to version.json by `bump`); `web/js/theme-boot.js` - applies the saved theme before paint.
- `web/js/util.js` - `h()` DOM builder (text nodes only), `setChildren`, toast, announce, safeUrl; `web/js/store.js` - prefs with memory fallback; `web/js/i18n.js` - he/en strings, `t()`, dates.
- `web/js/catalog.js` - pure catalog logic; `web/js/icons.js` - inline SVG icons; `web/js/share.js` - WhatsApp/share/copy links; `web/js/update.js` - store self-update + worker registration.
- `web/js/ui/home.js` - store front (search, chips, filter sheet, recent strip, grid); `ui/card.js` - app card + badges + action button; `ui/detail.js` - app page; `ui/guide.js` - install guide steps; `ui/mock.js` - phone illustrations; `ui/about.js` - about/copyright/contact/update; `ui/settings.js` - language (Hebrew default / English), appearance, reset of favourites + install marks; `ui/lightbox.js` - screenshot viewer; `ui/art.js` - AI-made illustrations (light/dark pairs) + category icons (CSS mask).
- `web/art/store/` - the ChatGPT visuals delivered from `docs/prompts/STORE_VISUALS_PROMPT.md`: `states/` (empty/offline/error/coming-soon), `install/` (guide strip), `categories/` (9 icons), `home/` (hero light/dark), `bg/` (page patterns), `icon-maskable.svg` (source for the maskable PNG).
- `web/data/apps.json` - the catalog; `web/art/icons/*` - app icons; `web/art/shots/<id>/*.jpg` - screenshots.
- `scripts/bump-version.mjs` - version bump (version.json, sw.js, appVersion.js, package.json); `scripts/static-checks.mjs` - syntax/banned APIs/CSP/SW consistency; `scripts/serve.mjs` - dev + e2e static server.
- `scripts/sync-catalog.mjs` - compares the catalog with the real apps and updates version/date/notes; `scripts/seed-catalog.py` - the original hand-written seed (reference only).
- `scripts/patch-release-checklists.mjs` - inserts the "update the store" step (`docs/APP_RELEASE_STEP.md`) into the other apps' release checklists (local clones).
- `scripts/make-icons.mjs` - PNG icons from icon.svg; `scripts/make-native-icons.mjs` - SVG icons from the native apps' adaptive launcher vectors; `scripts/capture-shots.mjs` - screenshots of the web apps from local clones.
- `tests/unit/catalog.test.js` (schema + real files + search/filter/sort), `i18n.test.js` (he/en parity, guide steps), `store.test.js` (prefs), `sync.test.js` (sync parsing, update compare), `version.test.js`, `docs.test.js`; `tests/e2e/smoke.mjs` - Playwright flows + axe + 320 px; `tests/e2e/journey.mjs` - screenshots of every screen (he + en).
- `.github/workflows/ci.yml` (checks), `pages.yml` (deploy `web/`), `sync-catalog.yml` (daily catalog sync).
