# Bootstrapping a new app (web + Android shell)

Order matters: **get CI green on an empty app before building features.**

1. **Repo** `ohadsam/<name>`, default branch `main`. Settings -> Pages -> Source: *GitHub Actions*; Actions -> General -> *Read and write permissions* (release job). Work on a branch (`claude/*` or `ccr-*`, both trigger CI).
2. **Copy from `templates/`**: `CLAUDE.md` (edit: names, rules), `workflows/ci.yml` + `workflows/pages.yml` (replace `stepup`/`StepUp` with the app slug/name), `scripts/` (`bump-version.mjs`, `static-checks.mjs`, `serve.mjs`), `tests/version.test.js` + `docs.test.js`. Create `package.json` (scripts: `test`, `check`, `e2e`, `serve`, `bump`; devDependencies only: `axe-core`, `playwright`), `docs/` skeleton (`CONTEXT.md` with the file map, `ARCHITECTURE.md`, `TESTING.md`, `CHANGELOG.md`, `USER_GUIDE.md`, `REQUESTS.md`, `RELEASING.md`, `ROADMAP.md`, `DESIGN_LANGUAGE.md`, `PENDING_CHATGPT_PROMPTS.md`), and `.claude/skills/release-checklist/SKILL.md` (copy `references/release-checklist.md`, specialise §0 with the app's audience).
3. **Web skeleton** (`web/`): `index.html` with strict CSP and `theme-boot.js` (no inline script), `manifest.webmanifest`, `sw.js` (see pwa-pages-actions §2), `version.json` `{version, versionCode}`, `js/app.js` (hash router), `js/util.js` (`h()` DOM builder with text nodes only), `js/i18n.js` (he + en maps, `t()`), `js/store.js` (localStorage with memory fallback, sanitise-on-read), `css/app.css` (tokens on `:root`, dark scheme, logical properties only), icons 192/512/maskable + `icon.svg`.
4. **Android shell** (`android/`): single module, package `com.<owner>.<app>`; Gradle reads `web/version.json` for versionName/versionCode; assets = `../web` copied at build; `MainActivity` (WebView on an in-app origin via `WebViewAssetLoader`, external links open in the browser, file/content access off), `NativeBridge` (validated, size-capped), committed signing key (`<app>.keystore`) used by debug and release, `INTERNET` only with a written reason in ARCHITECTURE.md. Details: `android-webview-shell.md`.
5. **Tests first run**: unit (`node --test`), e2e boot step + axe + 320 px overflow, Kotlin `BridgeLimitsTest`. Version test, docs test (file map lists every file), i18n parity test, CHANGELOG-has-this-version test.
6. **First release**: bump to 0.1.0, CHANGELOG, push to `main`, verify release asset + Pages URL (`https://ohadsam.github.io/<repo>/`). Hand the owner the PWA link and the APK link.
7. Write the first `docs/REQUESTS.md` ledger from the owner's brief, and `docs/CONTEXT.md` so a fresh session can continue from docs alone.
